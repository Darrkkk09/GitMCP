# GiTMCP frontend

React/Vite frontend for **GiTMCP: AI-powered GitHub Repository Intelligence**.

Run `npm install` and `npm run dev -- --host localhost`.
`VITE_API_BASE_URL` defaults to `http://localhost:8000`.
OAuth credentials and access tokens belong only on the backend; never put them
in frontend environment variables, localStorage, or UI state.

See [project setup](../README.md) and [OAuth testing](../docs/OAUTH.md).
